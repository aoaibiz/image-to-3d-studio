# GLB inspection viewer (phase one)

Run `npm ci`, then `node server.cjs` and open http://127.0.0.1:4173. Set `PORT` to select a different port. Choose a local GLB; it is processed locally. The server only serves an explicit list of viewer assets. External GLB resource URIs are rejected; a restrictive browser policy additionally blocks network connections and external images. Three.js 0.180.0 and Playwright 1.56.1 are pinned in package-lock.json.

Front is the GLB +Z direction, not a claim about the subject's semantic front. Presets use orthographic projection. Reset restores front view, model center and zoom. The SHA is calculated from the selected file; the download returns the original bytes. Manual orbit or zoom labels a saved capture `custom`; use a preset immediately before a named screenshot.

For repeatable screenshot evidence: `node proof.cjs <absolute-glb-path> <output-directory>`. It starts the server on an available loopback port, loads the selected file, emits material and clay screenshots for ten fixed views, and records SHA, lighting, camera convention and measured drag and zoom in a manifest. A locally installed Chrome/Edge or Playwright Chromium is required. The GLB must be self-contained; external resources and compressed extensions requiring additional decoders are not supported.

`node proof.cjs --synthetic <output-directory>` tests the viewer using a generated geometric fixture, explicitly synthetic and not a 3D inference result. It verifies more than a complete turn by actual mouse drags, wheel zoom, pan/reset, external URI rejection, server restrictions and exact-byte download. A genuine inference GLB must be supplied separately for the milestone. A recorded inference example is included under ../demo/generated/. The interactive server uses local dependencies.

Create a standalone preview with `node make-preview.cjs <absolute-model.glb> <absolute-preview.html>`. The HTML embeds the exact GLB and bundled viewer, and can be opened directly via `file://` without a server. It contains the model itself: share it only with people authorized to receive the GLB. `node proof.cjs` also creates and opens this preview, checking its SHA and external network activity. The synthetic test uses an embedded PNG texture in a GLB bufferView and checks that textured material differs visibly from clay in both server and offline viewers.
