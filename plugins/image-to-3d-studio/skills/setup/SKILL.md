---
name: setup
description: Set up the local Image to 3D Studio plugin and diagnose its service.
---
Check Node 22 and a local checkout. Run `npm ci` inside the checkout's `clients` directory. Follow `clients/README.md` to register the marketplace and run `plugins/image-to-3d-studio/bootstrap.mjs` with the explicitly chosen Codex home and checkout. Start the local studio service using its documented instructions. Restart Codex, then call the `diagnose` tool. Do not edit user-wide configuration without authorization, install globally, or expose the service on the network. Report missing prerequisites plainly.

The standard local engine is TripoSR. If the operator chooses the optional TripoSG shape engine during setup, use engine/TRIPOSG.md in the selected checkout, configure the job store once, and restart that Studio service. Explain the model download size, CPU time and upstream territorial terms. Check the selected pipeline with the diagnose tool. The image stays on the user's computer with either engine.

For automatic source analysis and hidden paint on the official Stable Fast 3D route, explain both recipients at setup. The user's foreground goes to the official Stability AI Space on Hugging Face using its anonymous allowance. OpenAI ChatGPT receives the metadata-stripped source for one observation and, if paint is needed, the source plus geometry guides for one generated sheet. On consent, run `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -AllowOfficialSpace -ChatGPTPhotoAnalysis -SendPhotoAndGuidesToOpenAI` and restart Studio. Confirm `sf3d-codex-observed-v1` in the service diagnostics. For later images use the ordinary generate tool with a single photo. To revoke the two recipients, select the local `triposr` configuration and restart Studio.

For an operator who chooses native Codex ImageGen for back-side paint, explain that a metadata-stripped photo and two-view geometry guide will go to OpenAI ChatGPT through their host account, up to one call per job, subject to that account's usage limits. On consent, configure `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -SendPhotoAndGuidesToOpenAI -UseCodexHost`, then restart Studio. This host and Studio must share a filesystem. The CLI/MCP reads the generated local token from the Studio job store. For a custom store, set `STUDIO_HOST_TOKEN_FILE` to its `host-access.token` path. Keep its contents private. Return to `--engine triposg` and restart Studio to use local paint again.
