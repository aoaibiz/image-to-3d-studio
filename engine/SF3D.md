# Stable Fast 3D 公式 Space による生成

Stability AI が Hugging Face で公開しているデモを、本人の回線と匿名利用枠で明示的に選択するための Python アダプターです。通常のローカル生成は従来どおり利用できます。利用者には、対象の前景画像を公式 Space に送信することと、本人の匿名 ZeroGPU 枠を使うことを伝え、了承を得てから呼び出してください。空き枠やサービス継続は提供元に依存します。[公式デモ](https://huggingface.co/spaces/stabilityai/stable-fast-3d)

## 呼び出し

```python
from pathlib import Path
from engine.sf3d_provider import generate

# source_sha256 は前景作成時に記録した元画像の SHA-256。
receipt = generate(
    foreground=Path("private/job-123/foreground.png"),
    source_sha256=source_sha256,
    work=Path("private/job-123/sf3d"),
    allow_official_space=True,  # 本人が送信先と利用枠を了承した場合だけ設定
    progress=print,            # 実イベント名を受け取る省略可能な関数
)
print(receipt["artifact"]["sha256"])
```

ジョブごとに専用の非公開ディレクトリを割り当てます。元画像の SHA-256 と透過前景の対応は呼び出し元が管理し、このアダプターは元画像、前景 PNG、実際の送信 PNG の各ハッシュを受付記録に結び付けます。入力は透明な背景を持つ RGBA PNG 1枚です。送信時に長辺を最大 1152 ピクセルに縮小し、透明部およびアルファ値が 48/255 未満の薄い境界の RGB を消去し、ファイル名を固定してピクセルから PNG を再構成します。写っている部分は前景として送信されます。

写真の送信先は `https://stabilityai-stable-fast-3d.hf.space` です。公開リビジョンの照合には `https://huggingface.co/api/spaces/stabilityai/stable-fast-3d` を使います。こちらに写真は送信しません。アダプターは匿名接続専用で、API キー、既存ログイン、課金契約を読み込みません。

送信した前景1枚を提供元の前処理で確認し、形状生成を1回キューに入れます。前景比は 0.85、リメッシュは無効、頂点数は提供元の既定値、テクスチャは 1024 ピクセルです。Space の署名と Gradio 4.41.0 の SSE プロトコルを確認し、互換性に変更があれば送信前に停止します。

## 保存と再開

`model.glb` は提供元が返したテクスチャ入りの元バイト列です。静的三角形、頂点・UV・法線、埋め込みテクスチャ、参照インデックス、サイズを点検してからファイルを確定し、SHA-256 を返します。48 MiB を超えるモデルは受理しません。形状を簡略化したりテクスチャを書き換えたりする工程はありません。完成扱いにする前に、通常の glTF Validator と、同一 GLB の材質あり・無地の全方向検品を通してください。背面の色や形状には提供元の推定が含まれます。

`provider.json` に入力ハッシュ、設定、Space リビジョン、受付時刻、イベント ID、再開情報を保存します。セッション ID と一時的な提供元パスが含まれるため、このファイルを公開せず、呼び出し元では返却された項目だけを必要に応じて表示します。

通信が切れて `Pending` が返ったときは、同じ入力・ディレクトリ・許可設定で `generate` を再開します。キュー投入直前に受付状態を保存しており、再開時は同じセッションのイベントを購読します。再開操作で同じ生成リクエストを再送することはありません。完了済みなら手元のハッシュを照合して結果を返します。アップロード結果が不明な場合、または提供元のイベント保存期間が過ぎた場合は、元の受付を未確認として扱います。

任意の `cancelled` コールバックが真を返すと、ローカルで `InterruptedError` を返して待機を止めます。進行中の HTTP 読み取りにはタイムアウト分の遅れが生じます。提供元がすでに受理した処理や利用枠の消費は取り消せません。

## 検証と利用条件

`python -m unittest quality.test_sf3d_provider -v` はネットワークを使わず、受理、曖昧な応答、再開、同一成果物、異常データの扱いを検証します。2回の実生成で保存した非公開の記録がある場合には、そのディレクトリを `STUDIO_SF3D_REPLAY` に指定すると、両方の実イベント種別・ID・ステータスと実 GLB のバイト列も再生します。実験当時の送信 PNG のハッシュと現在の透明画素処理後のハッシュは別々に検証します。記録に含まれなかった Gradio の応答ラッパーと一時パスにはテスト値を与えます。公開テストに使う小さな三角形は形式検査用です。

配布対象はこのリポジトリのクライアントコードです。モデル・重み、第三者が提供した画像、検証に使った提供元の実 GLB は配布物に含みません。元画像を送信する権利と出力の用途を確認し、モデルおよびホストに適用される条件を利用者ごとに確認してください。[モデルカード](https://huggingface.co/stabilityai/stable-fast-3d)・[モデルのライセンス](https://github.com/Stability-AI/stable-fast-3d/blob/main/LICENSE.md)・[Hugging Face 利用規約](https://huggingface.co/terms-of-service)
