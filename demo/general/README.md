# 一般物体の実写真からの生成例

未加工の写真を Windows の標準ローカル生成経路へ1枚ずつ投入した結果です。TripoSR による形状推論と輪郭・外観の仕上げを使いました。表面の質感、部品の境界、写真に写らない面には差が残ります。

## ティーポット

注ぎ口と取っ手の穴を保っています。上縁がゆがみ、背面に原写真では確認できない波状の凹凸が残っています。 GLB SHA-256 は `9537a5eef851611acde584bd55f61623626058ec0c8b7238abf29d0334a5649a` です。

[360°ビューアー](https://aoaibiz.github.io/image-to-3d-studio/objects/teapot/) ・ [入力写真](teapot.jpg) ・ [材質・無地の比較](teapot-comparison.jpg)

原写真「Davenport Pottery and Porcelain Factory (British) - Teapot - 1940.10.a - Cleveland Museum of Art.jpg」 Cleveland Museum of Art。写真を背景分離し、立体形状とテクスチャを生成しました。 [写真の出典](https://commons.wikimedia.org/wiki/File:Davenport_Pottery_and_Porcelain_Factory_%28British%29_-_Teapot_-_1940.10.a_-_Cleveland_Museum_of_Art.jpg) ・ [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

## コンパクトカメラ

正面にはレンズと文字が見えます。無地ではレンズの段差が浅く、側面の反りと背面の凹凸が残っています。 GLB SHA-256 は `588b9c21c2223cd394054c71939de618a32594a9a73f795523dfbc0dc275018d` です。
