# Original product artwork

The toy car illustration in product.svg and its raster export product.png were created specifically for this project. No third-party images, logos, or 3D assets were used. The artwork is dedicated to the public domain under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/.

product-cutout.png is derived from product.svg with the white background and cast shadow removed. It retains a transparent alpha channel and the same CC0 dedication.
